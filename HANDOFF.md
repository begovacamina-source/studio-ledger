## Tests and CI

- `npm test`: Vitest unit and component tests in `src/`. `npm run test:e2e`: Playwright in `e2e/` against `vite preview`, with the clock fixed at 2026-10-20 (`e2e/fixtures.ts`); locally it uses the installed Chrome. It runs the core journeys, the keyboard flows, and the text and non-text contrast checks.
- Keyboard tests: `tabTo()` presses Tab until a control has focus and fails if a stop shows no 3:1 focus indicator; arrows are held 50 ms (`arrow()`), because Radix moves focus a tick after keydown.
- `.github/workflows/ci.yml` runs lint, unit tests, the build and the journeys on every pull request and push to `main`, and keeps the Playwright report as an artifact. Merge a pull request only once its CI run is green: branch protection isn't available on the free plan, so nothing blocks a red merge.
